# 考试备考执行框架与索引

> **文档性质**：方法论框架 + 目录索引。具体考试内容、时间、基础由专项对话填充。
> **核心硬约束**：每次学习以「实际获得知识」为核心，禁止以「学习时长 / 页数 / 视频数」作为成功指标。
> **理论来源**：可控小成功与进度评判调研、不确定性下的坚持调研、动作自省与反馈调研（training-tracker-docker/docs/ 下三份）。

---

## 0. 给专项对话的交接说明

你（专项负责这个考试的对话）的任务：

1. 读本文档，理解三层指标体系和每次学习 SOP
2. 填充 `01-考试信息与目标.md`（考试名称 / 时间 / 科目 / 通过标准 / 当前基础）
3. 做 `02-知识点分解.md`（按考试大纲 / 教材，列出全部知识点 + 掌握状态）
4. 制定第一周 `03-周计划/`
5. 初始化 `04-知识获得账本.md`、`05-错题本.md` 模板
6. 之后每周循环：执行周计划 → 记录知识获得 → 周日复盘 → 调整下周

**你不能做的事**：
- 不能把「学了 X 小时」「看了 X 页」当成进步证据
- 不能跳过 L1 知识获得记录直接安排下周
- 不能在没有月度模考的情况下宣称「在进步」

---

## 1. 核心原则（不可违反）

| # | 原则 | 为什么 |
|---|---|---|
| 1 | **知识获得优先于时间投入** | 每次学习结束必须能说清「我今天具体学会了什么」，时长是成本不是成果 |
| 2 | **三层指标闭环** | L1（每次）/ L2（每周）/ L3（每月），单一信号必自欺 |
| 3 | **先自检后验证** | 做题先自己估正确率再对答案，防外部反馈依赖（guidance hypothesis） |
| 4 | **小成功可见** | 每次的「获得知识」必须记录，这是效能感（mastery experience）的来源 |
| 5 | **定期换挡** | 区分「坚持」和「死磕」，有明确的放弃 / 调整检查点 |
| 6 | **错误是学习触发器** | 做错的题比做对的题价值大——错误后几百毫秒前额叶自动募集，立刻改最有效 |

## 2. 三层指标体系

### L3 Lagging（月度 · 证明 · 不可造假但反馈慢）

- **全真模考分数**（限时、无资料、同时间段、和真实考试一致）
- **考试通过概率自评**（基于模考趋势，不是感觉）
- 频率：每 4 周一次，和学习周期对齐
- 作用：证明你是否真的在靠近目标

### L2 Leading（每周 · 预测 · 即时但需防 Goodhart）

- **知识点掌握率**：本周目标知识点中，能**独立复述 / 解题**的比例
- **错题重做正确率**：上周错题本周重做的正确率
- **无提示回忆率**：合上资料能写出的知识点比例
- 频率：每周日复盘时计算
- 作用：预测下个月 L3 会不会涨

### L1 Mastery（每次学习 · 喂养效能感 · 核心载体）

- 本次学习的**具体知识点清单**（不是「学了第 3 章」，而是「掌握了 XX 概念的 YY 条件 / 能解 ZZ 类题」）
- 每个知识点必须通过验证：**能独立做对一道相关题** 或 **能合上书画出逻辑图 / 写出推导**
- 每次学习结束记录 1-3 条「今天获得了什么知识」，具体可检验
- 作用：让大脑持续收到可信的「在靠近」信号（多巴胺 = 进展评估货币）

### 信号污染检测

> **L2 连续涨而 L3 八周不动 → 指标被污染（Goodhart's law）**

可能的污染形式：
1. 只练已经会的题（降难度刷正确率）
2. 背答案而不是理解（换题型就错）
3. 学习时长涨但知识获得不涨（打卡幻觉）
4. 自评过度乐观（illusions of competence）

## 3. 每次学习 SOP（90-120 分钟一个单元）

### 前置（5 分钟）：设定获得目标

1. 从周计划中选今天的知识点范围
2. 写下来：**学完后我应该能做什么？**（具体、可检验）
   - 坏目标：「学完微积分第 3 章」
   - 好目标：「能独立用洛必达法则解 0/0 型极限题，正确率 ≥ 80%」

### 学习（60-90 分钟）：主动获取

3. **主动学习**，不是被动阅读：
   - 边学边自问自答（「这个条件为什么必要？去掉会怎样？」）
   - 学完一个小节，**合上书画逻辑图 / 写关键点**（无提示回忆）
4. **做题验证**：
   - 先自己做，不看答案
   - 做完先**自评正确率**（「这 5 题我觉得对了几题」），再对答案
   - 记录自评偏差（训练自我评估能力）
5. **错题处理**（最重要的环节）：
   - 不只是看答案，要写：
     - 我之前的思维错在哪？（知识缺口 / 审题 / 计算 / 时间）
     - 正确路径是什么？
     - 下次遇到同类题的触发信号是什么？

### 收尾（10 分钟）：记录获得

6. **无提示自检**：不看任何资料，写出今天获得的 1-3 条具体知识
7. **记录到知识获得账本**（`04-知识获得账本.md`）：
   ```
   ## 2026-10-15
   - 获得：洛必达法则适用条件（0/0 或 ∞/∞，可导，分母导数非零）
     验证：独立做对 5 题中 4 题（P12 例 3/4/5/7）
   - 获得：等价无穷小替换的使用边界（乘除可换，加减谨慎）
     验证：能合上书写出 3 个反例
   - 未掌握：泰勒展开展开到第几项的判断 → 进入待攻克清单
   ```
8. **标记未掌握点**：今天没搞懂的，进入下周的「待攻克清单」

## 4. 每周复盘 SOP（周日 · 30 分钟）

1. **盘点 L1**：本周共获得多少条知识？哪些是真掌握（能独立解题）？哪些只是「看过」？
2. **计算 L2**：
   - 知识点掌握率 = 真掌握数 / 本周目标数
   - 错题重做正确率 = 上周错题本周重做正确数 / 总数
3. **对比 L3 趋势**（如果有模考数据）
4. **虚假进步三问**：
   - 这些知识是在**边缘难度**获得的吗？（还是只是复习了已经会的）
   - **换一种题型 / 问法**还能做对吗？
   - 和模考分数**同向**吗？
5. **调整下周计划**：
   - 未掌握点优先安排
   - 已掌握点减少复习频率（间隔重复：1 天 / 3 天 / 7 天 / 14 天）
   - 如果某类知识点连续 2 周搞不定 → 换学习方式（视频 / 做题 / 讲解 / 画图 / 找老师）

## 5. 月度测试协议（每 4 周）

1. **全真模考**：限时、无资料、和真实考试同时间段、用真题或高质量模拟题
2. **考后不立刻看分数**，先自评每部分正确率（「我觉得阅读对了几题」）
3. **对答案，计算自评偏差**（自评 vs 实际）——偏差缩小 = 自我评估能力在进步
4. **错题分类**：
   - 知识缺口（根本不会）→ 回到知识点分解
   - 审题错误（会但看错）→ 训练读题标记习惯
   - 时间分配（会但没时间）→ 模考策略调整
   - 计算 / 书写失误 → 针对性训练
5. **更新 L3 趋势**，画模考分数曲线，判断是否在靠近

## 6. 不确定性下的坚持机制

### 身份锚点
> 「我是一个每次学习都能说清自己获得了什么的人。」

不是「我要通过 XX 考试」（结果目标，被不确定击溃），而是身份驱动（每个行动都是对想成为的人的投票）。

### 小成功账本
`04-知识获得账本.md` 就是你的「进步证据库」。怀疑自己时翻账本——你不是在「坚持」，你是在持续获得知识。

### B 计划（if-then）
- 如果某类知识点反复搞不定 → 换学习方式，不是「更使劲」
- 如果某天状态差 → 只做 1 个最小知识单元（25 分钟），保持习惯不断
- 如果模考崩了 → 先分析错题分类，不否定整体

### 放弃 / 调整检查点
> 连续 4 周 L2 不涨 + 已换 3 种学习方式 → 考虑调整目标范围或考试时间

这不是失败，是区分 The Dip（进步慢但真实，熬）和 Dead End（无信号改善，转）。
