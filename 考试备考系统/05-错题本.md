# 错题本

> 错题是学习触发器（错误后几百毫秒前额叶自动募集，立刻改最有效）。
> 每道错题必须写清错误原因，不只是抄答案。

## 格式模板

```
### [日期] 科目 / 模块 / 题号
- **题目**：（简要描述或标注来源页码）
- **我的答案**：（错在哪一步）
- **正确答案**：
- **错误分类**：⬜ 知识缺口 / ⬜ 审题错误 / ⬜ 计算失误 / ⬜ 时间不够 / ⬜ 其他
- **错误原因**：（具体：我当时怎么想的，为什么错）
- **正确路径**：（正确的思考步骤）
- **触发信号**：（下次遇到什么特征要想到这个方法）
- **重做记录**：
  - 1 天后：⬜ 正确 / ⬜ 仍错
  - 3 天后：⬜ 正确 / ⬜ 仍错
  - 7 天后：⬜ 正确 / ⬜ 仍错
```
