## 题1 · DFD数据流图（~15分）
> 状态：⚪未掌握 ｜ 素材：2304次/49篇

### 四元素
- 外部实体=矩形（系统外的人/系统）
- 加工=圆/圆角矩形（处理数据）
- 数据存储=双横线（文件/表）
- 数据流=箭头

### 三大题型套路
1. **找外部实体**：从需求描述里找"谁给系统发数据/谁从系统收数据"，不能是系统内部模块。
2. **找数据存储**：看哪个数据被加工后"存下来"，通常一进一出的数据流对应一个存储。
3. **补缺失数据流**：
   - **父图子图平衡**：子图所有输入输出数据流 = 父图中对应加工的输入输出，缺哪个补哪个。
  - 状态：⚪未掌握 ｜ 素材：4次/4篇
   - 技巧：缺的数据流通常是"存储↔加工"之间或"实体↔加工"之间；对着需求逐句核对。
4. **结构化语言描述加工逻辑**：用IF-THEN-ELSE伪代码写，对需求条件分支。

### 拿分底线
- 第1问（找实体）+第2问（找存储）= 白送分，必须全对。
- 第3问（补数据流）= 对着父图子图平衡找，能拿80%。
- 第4问（结构化描述）= 写伪代码，能拿一半。

# 三、易混点对比表

> 丢分重灾区，单独成节。

| 对比项 | 区别 | 记法 |
|---|---|---|
| **内聚 vs 耦合** | 内聚=模块内部联系紧不紧（越高越好）；耦合=模块间联系紧不紧（越低越好） | "内紧外松" |
| **include vs extend** | include=基用例必执行被包含用例（箭头指向基用例）；extend=扩展用例条件触发（箭头指向扩展用例） | include是"必做"，extend是"彩蛋" |
| **聚合 vs 组合** | 聚合=空心菱形，部分可脱离整体（球队vs球员）；组合=实心菱形，部分不能脱离（订单vs订单项） | 空心=可拆，实心=共存亡 |
| **进程 vs 线程** | 进程=资源分配单位；线程=CPU调度单位；线程共享堆，私有栈 | 进程=房子，线程=房间里的人 |
| **S锁 vs X锁** | S锁=读锁，可多个S共存；X锁=写锁，独占 | 读共享，写独占 |
| **重载 vs 重写** | 重载=同类同名不同参（编译期）；重写=子类改父类方法（运行期） | 重载=同名片，重写=改爹的 |
| **时间局部性 vs 空间局部性** | 时间=刚访问的马上又访问（循环）；空间=访问了相邻的（数组） | 时间=同一个点反复，空间=附近的点 |
| **顺序查找 vs 折半查找** | 顺序=无序表O(n)；折半=有序表O(logn) | 有序才能折半 |
| **CRC vs 海明码** | CRC=检错不纠错；海明=检错+纠错 | 海明更强 |
| **中断 vs DMA** | 中断=CPU要介入处理；DMA=外设直接与内存交换，CPU只首尾介入 | DMA更省CPU |
| **FIFO vs LRU** | FIFO=先进先出（可能Belady异常）；LRU=最近最久未使用（更优） | LRU聪明 |
| **甘特图 vs PERT图** | 甘特图=条形图看进度，不显示依赖；PERT=网络图显示依赖+关键路径 | PERT能算关键路径 |
| **Alpha vs Beta测试** | Alpha=开发方现场；Beta=用户实际环境 | Alpha在厂里测，Beta在用户家测 |
| **改正性 vs 完善性维护** | 改正=改bug；完善=加新功能（占比最高） | 完善性是占比王 |
