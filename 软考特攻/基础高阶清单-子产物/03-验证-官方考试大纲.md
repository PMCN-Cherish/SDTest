## ③ 大纲要求层级梳理

**大纲确有明确的层级分级表述，分两层：**

**第一层——官方"考试要求"正文（12 条）用词分级：**
- **掌握**（最高频）：数据表示与运算、应用/离散数学、计算机体系结构、操作系统与程序语言基础、C 及 C++/Java 之一、软件设计方法与技术、信息技术标准/安全/法律法规。
- **熟练掌握**（最强级，仅 2 处）：常用数据结构与常用算法；软件设计的方法和技术。
- **熟悉**：数据库、网络、多媒体；软件工程、软件过程改进、项目管理。
- **了解**：编译程序基本知识；信息化、计算机应用基础知识。
- **能力要求**：正确阅读和理解计算机领域英文资料。

**第二层——大纲"考试范围"正文中的等级符号（据大纲 PDF 原文）：**
- 大纲在每章知识点后标注 **"Ⅰ""Ⅱ""Ⅲ"** 三个等级，注释为"I、II 和 III 表示掌握或熟悉……"（即对每个细知识点再做要求程度分级）。
  - 来源：大纲 PDF 原文（信管网下载件 snippet："说明: 'I'、'II'和'III'表示掌握或熟悉…"）。

> 结论：大纲**有明确的重难点/要求分级**——既用"熟练掌握 > 掌握 > 熟悉 > 了解"的词级，又用 Ⅰ/Ⅱ/Ⅲ 符号对单知识点分级。并非无分级。

## ④ 下午题（科目2：软件设计 / 应用技术）规定

官方仅规定科目为"软件设计，计算机化考试，问答题"，**未在考试说明正文里逐题列出题型**。下午题固定题型来自大纲"考试范围（科目2）"与历年真题稳定结构：

| 题号 | 是否必答 | 题型 | 考点 |
|---|---|---|---|
| 试题1 | 必答 | 数据流图 DFD | 补外部实体/数据存储/加工、补数据流、找错误/遗漏数据流 |
| 试题2 | 必答 | 数据库设计 | E-R 模型→关系模式、主键/外键、规范化、增实体 |
| 试题3 | 必答 | UML 建模 | 类图/用例图/活动图/状态图补全、关联关系说明 |
| 试题4 | 必答 | C 语言算法填空 | 分治/贪心/动态规划/回溯等算法策略实现填空 |
| 试题5 | 二选一 | C++ 程序设计 | C++ 语法 + 设计模式代码填空 |
| 试题6 | 二选一 | Java 程序设计 | Java 语法 + 设计模式代码填空 |

- 结构：共 6 题，**前 4 题必做，后 2 题（C++/Java）二选一**。
- 设计模式题自 2006 年起稳定考查，结合类图 + 代码填空。
- 来源：希赛网《应用技术历年考试范围》https://m.educity.cn/rk/5435502.html ；CSDN 下午题统计 https://blog.csdn.net/aerchi/article/details/78131637 ；信管网分值分布 PDF。

## ⑤ 与常见备考认知 / 知识地图的出入点

1. **大纲版本不是"2022版"，而是"2018审定版"**。教程常被记成"第5版/2021"，但它是依据 2018 大纲编写的配套教材；二者配套且现行有效。——与"软考大纲可能是2022版"的预设不一致。
2. **机考不换大纲**：2024 起机考只是形式变化（选择题/问答题仍在两科目内），命题范围、大纲层级完全沿用 2018 版。——"机考=新大纲"是误读。
3. **大纲确有分级**：官方用"熟练掌握/掌握/熟悉/了解"四级 + 考试范围 Ⅰ/Ⅱ/Ⅲ 符号。——若知识地图假设"大纲无分级"，此为冲突点：大纲**是有分级的**。
4. **"熟练掌握"只给了两处**：常用数据结构与常用算法、软件设计的方法和技术——这是大纲明文圈定的最强要求点，可作为高阶/重点章节的官方背书（区别于坊间自划重点）。
5. **用户给的 9 模块漏了两个大纲明确列入的内容**：程序设计语言/编译原理（"了解编译程序"）与多媒体技术（"熟悉"）。它们在上午题稳定占分，基础清单不应遗漏。
6. **下午题题型由大纲"考试范围（科目2）"与真题结构固化，官方考试说明页未逐题列明**——备考认知里"DFD/ER/UML/算法/设计模式五件套"与大纲范围一致，无冲突；但严格说"下午固定题型"是**大纲范围+历年真题稳定结构**的结论，而非考试说明正文逐条规定。
