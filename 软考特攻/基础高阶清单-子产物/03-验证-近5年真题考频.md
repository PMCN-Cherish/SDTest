> 用途：为「考点基础/高阶划分」提供外部交叉验证。
> 调研时间：2026-10-14。2023下半年起全面机考，2024年为完整机考年度（科目连考、分批次）。
> 数据性质说明：真题官方不公布完整原卷，本文证据以「考友回忆版 + 机构真题库统计 + 备考笔记」为主，均已标注性质。

### 1.2 与常识分布的出入（重点）

1. **面向对象被严重低估**：用户预设~7分，实测上午题约11分、占比15%，是上午题题量第一大模块（含OO基本概念64题、OO分析与设计122题、设计模式58题）。这是最大出入点。
2. **数据结构与算法被低估**：用户预设~7分，实测约9分、占比12.4%，题量排名第2。
3. **软件工程实际约13分而非15分**：若严格按「软件工程基础知识」口径约9.8%（~7分），加上「系统开发与运行」（结构化分析设计/系统设计/测试维护）才到~13分。用户预设的~15分偏宽松，需把项目管理(PERT/关键路径)、测试、质量模型都算进来才成立。
4. **操作系统/数据库实际约6分而非7分**：两者占比均约8%。
5. **程序设计语言（文法/编译原理）与信息安全**为独立小模块（各约5~6分），用户预设表中未单列，容易被忽略。

## 二、高频考点清单（按模块，标注出现年份/证据）

### 3.2 近年稳定性与变化

- **题型结构完全稳定**：DFD / ER→关系模式 / UML / C算法 / 设计模式(C++或Java二选一) 这5类题型在2021~2025所有回忆版中均未变化。
- **机考改革（2023下半年起）**：由纸笔改为机考，**科目连考、分批次**，科目一节余时长可给科目二用；但下午题「4道必做+最后2道二选一」的结构未变。来源：工信部教育与考试中心公告 https://www.miiteec.org.cn/news_details?code=17149241DJ8Z1BLS
- **内容题材贴近热点**：2025下DFD出现「大模型知识库问答」、英语题以「大模型时代对software design影响」为题材——机考后题目顺序打乱、题材更紧跟AI/云计算，但考点内核不变。
- **算法题偏好回溯/动态规划**：近3年下午算法题集中在回溯（N皇后、子序列）与动态规划（最长公共子序列）。
- **设计模式下午题固定为代码填空5空**：2025下为桥接模式；上午题另设4场景选模式（observer/factory/bridge/strategy）。

## 四、考频结论汇总

### 4.1 模块分值分布 vs 常识
- **基本一致**：计组~6分、网络~5分、知产~3分、英语5分。
- **明显出入**：
  - 面向对象实际~11分（上午题第一大模块），远高于预设的~7分；
  - 数据结构与算法实际~9分，高于预设~7分；
  - 软件工程实际~13分（含项目管理/测试/系统开发），预设~15分偏宽松；
  - 操作系统/数据库实际约6分，预设~7分略高；
  - 程序设计语言（文法/编译）与信息安全为独立小模块（各约5~6分），预设表遗漏。

### 4.2 「几乎每年必考」的5个核心考点（上午题）
1. **McCabe环路复杂度 + 测试路径覆盖**（软件工程，每年1~2题）
2. **关键路径/PERT网络图计算**（软件工程，项目管理子项题量第4）
3. **PV操作/进程同步互斥 + 页式存储/页面置换**（操作系统，进程管理59题）
4. **设计模式场景判定 + 下午代码填空**（面向对象，上午+下午双考，设计模式58题）
5. **流水线计算 + 校验码/补码浮点数**（计组，或等价替换为「哈夫曼树+排序」数据结构高频组合）

> 备选高频组合（同为近5年稳定出现）：ER→关系模式（下午）、UML建模（下午）、开发模型/内聚耦合、范式判定、网络分层与加密。

### 4.3 下午题稳定性
- **高度稳定**：DFD / ER→关系模式 / UML / C算法填空 / 设计模式代码填空(C++或Java二选一)，5类题型近5年未变；机考仅改形式（连考、题目顺序打乱），未改题型结构。

### 4.4 数据可信度与未查到项
- 已查证：下午题5类题型结构、机考连考规则、上午题模块占比（真题库统计+备考笔记双源印证）。
- 推断：具体考点「出现年份」基于考友回忆版与真题库题量分布，非官方逐题逐年统计，存在±1年误差。
- 未查到：官方逐题逐年的精确分值细目表（中国计算机技术职业资格网仅给科目形式，未公布每题分值归属）；2021~2022年完整原卷（仅有2023下~2025下回忆版较完整）。
