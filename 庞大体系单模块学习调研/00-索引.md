## 三、30秒结论速览

**1. 单模块攻克的黄金流程（跨01/02/04共识）**
`选模块（分值×A类数×接壤）→ 盘点考点（A类★高素材优先，一次≤6条）→ 首轮输入（只读字幕1-2篇）→ 主动回忆自测（合书复述+真题，≥70%过）→ 弱点回补（只回错点片段）→ 48h间隔回访 → 状态推进（⚪→◐→✅）→ 转下一模块`

**2. 六环循环（用户骨架）与证据挂接**
知识引入（生成效应/前测）→ 知识学习（分块/认知负荷）→ 自我纠正（检索练习/测试效应，**最大失败点=对了答案就翻篇**）→ 反复调试（交错/间隔/刻意练习，**状态字段⚪◐✅即"反复调试"的进度载体**）→ 继续下一个（掌握学习：未达标不推进）→ **中断休息（间隔效应+睡眠巩固+认知恢复，休息不是浪费，是巩固环节本身）**

**3. 中断休息的三条硬证据**
- 睡眠期大脑重放白天内容完成巩固（★★★）——10天里熬夜=抵消当天学习
- 觉醒期休息（wakeful rest）本身促进记忆保持（★★）
- 间隔效应=Cepeda：分散优于集中，"休息即间隔"（★★★）
- 疲劳信号（出现任一条立即停手）：同一考点连续2次回忆失败 / 自测连错3题 / 连续40分钟涣散 / 同一材料第2遍仍卡壳 / 23:30硬截止 / 身体信号（眼睛干涩坐不住）

**4. 10天冲刺排序（04已按知识地图实算）**
软件工程(332) → OOP UML+设计模式(173) → 数据结构(137) → 计组(66) → 操作系统(63) → 数据库(55) → 网络(25) → 知识产权(3) → 专业英语(0投入)；Day1起每天插1个下午题模板；Day7/D9两次整套限时模拟，错题考点强制回退◐。

**5. 总策略一句话**（01推断+02案例互证）
`每天真题/自测（检索+掌握学习）× 次日复习（间隔）× 只错难题（刻意练习）× 不熬夜（睡眠）× 状态字段按"能否提取"更新（不是"看过没看过"）`，砍掉反复阅读/划重点/抄书式笔记。
