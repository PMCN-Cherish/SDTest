## 一、模块优先级：算法与真实排序

### 1.1 优先级公式

```
模块优先级分 = 模块分值 × 该模块A类考点数 × (1 − ✅占比) × 下午题接壤系数
接壤系数：接壤≥1道下午题 = 1.3；无接壤 = 1.0
当前✅占比 ≈ 0（全部⚪），所以首轮排序 = 分值 × A类数 × 接壤系数
```

- **分值**：知识地图头部已标注（①15 / ②7 / ③6 / ④7 / ⑤7 / ⑥5 / ⑦7 / ⑧3 / ⑨5）。
- **A类考点数**：从知识地图逐条清点（下表为人工清点真实值）。
- **下午题接壤**：知识地图"接壤"字段。接壤=一分投入同时拿上午+下午两分。

### 1.2 真实计算与排序清单

1. **素材充足但未掌握的A类考点优先于素材少的B类**。例：耦合7级（素材834次/47篇，A类）远优先于Alpha测试（A类但0次/0篇）。

## 二、单模块攻克流程（7步，可直接照做）

> 以"首攻1个上午模块"为单位。每个模块预计2-3天闭环，不许一天开两个。

| 步骤 | 做什么 | 用什么资产 | 状态字段怎么驱动 | 预计耗时 |
|---|---|---|---|---|
| **1. 盘点考点** | 打开知识地图该模块小节，把考点按四列排序：A类在前、同考频下★★★在前、素材≥20篇在前。圈出今天要啃的3-6条（不超过6条） | `01-知识地图-L3.md` 对应章节；"状态/考频/难度/素材"4字段 | 先全部过一遍：标⚪的=今天目标；标◐的=进回访槽；标✅的=只在回访碰 | 15分钟 |
| **2. 首轮输入** | 按§三映射规则，给今天的每条考点挑字幕：素材≥10篇→只读播放量最高1-2篇；素材3-9篇→全读；素材0-2篇→改用zst长字幕或附录视频链接。**只读字幕，不看整段视频** | `字幕\`目录按"模块群-知识点群"前缀筛文件；`00-素材库总索引.md` 的zst系列/精品短视频表 | 读完一条就把它从⚪改为◐（写在知识地图该行末尾） | 60-90分钟 |
| **3. 主动回忆自测** | 合上书，对每条考点：①脱稿复述"要背的话"；②做1-2道知识地图"典型考法"对应的题（直接用zst上午题字幕里的真题片段，或知识地图附录用例）。A类要求复述≥80%要点+例题≥70%正确；B类≥60% | 知识地图"典型考法"字段；zst上午题#X字幕；易混点表 | 达标→该条标✅；不达标→保持◐并写进"今日弱点清单" | 40-60分钟 |
| **4. 弱点回补** | 对着"今日弱点清单"逐条定位：考点→知识点群→具体字幕文件名→具体BV号。只重读弱点对应的那一篇，不重看整个模块 | `字幕\知识点群_*.md` 具体文件；知识地图"素材：N次/M篇"字段确认素材充足度 | 回补后再自测一次；还不行→降级处理（只背"要背的话"一句话，放弃深挖） | 30-45分钟 |
| **5. 状态推进** | 把今天所有考点的最终状态写回知识地图：⚪/◐/✅。**每条都要改，漏改=白学** | `01-知识地图-L3.md` 行内"状态：X" | 当晚必填；✅的考点登记"回访日期=今天+2天" | 5分钟 |
| **6. 48h间隔回访** | 明天起的每天固定30分钟槽：只翻48h前标✅/◐的考点，脱稿复述。通过→回访次数+1；失败→✅回退为◐，进明日弱点清单 | 知识地图✅/◐行 + 自己记的回访日期 | 连续2次通过的✅→降频（考前再碰）；失败即回退 | 每天30分钟 |
| **7. 转下一模块** | 触发条件：本模块A类考点✅率≥80%，且回访槽无新回退。满足→按§一优先级清单开下一模块；不满足→第二天先补本模块再推进 | 知识地图该模块状态统计 | 未闭环不转模块（防崩机制） | — |

## 三、状态机判定表（可直接照做）

### 3.1 状态定义与转换条件

| 当前状态 | 转换条件（必须同时满足） | 目标状态 |
|---|---|---|
| ⚪未掌握 | 读完≥1篇指定字幕，且能说出"要背的话"大意（不要求全对） | ◐ |
| ◐学习中 | ①脱稿复述"要背的话"≥80%要点；②做≥1道典型考法例题，正确率≥70%（B类考点降为60%）；③知识地图"要背的话"里的关键字/公式/排序无错位 | ✅ |
| ✅已掌握 | 48h后回访：脱稿复述≥80%，无明显遗忘 | 保持✅，回访计数+1 |
| ✅已掌握 | 回访失败（要点遗忘≥30%或例题做错） | 立即回退◐，进次日弱点清单 |
| ✅已掌握 | 连续2次回访通过 | 降频：不再进每日回访槽，只在考前2天滚一遍 |
| 任意状态 | 做整套模拟/真题时该考点对应题目做错 | 立即回退◐，不管之前是不是✅ |

## 四、素材→字幕映射规则

### 4.1 文件名结构

字幕目录 `软考特攻\字幕\` 下两类文件：

1. **445篇批量字幕**：`知识点群_BV号.md`
   - 例：`软件工程-内聚耦合_BV1gk4y1u7f9.md`、`操作系统-PV操作_BV1af421z7Hk.md`、`UML-用例图类图_BV1Wu4y1Y7ya.md`、`下午题-DFD_BV1ta4y137Hi.md`
   - 前缀 = "模块群-知识点群"，**不是**知识地图里的单条考点名。
2. **30篇精品字幕**（索引§四已列）：`zst上午题#X-模块.md`、`肥猫简图-UML类图6min.md`、`圆酱-PV秒杀12min.md` 等。

### 4.2 映射流程（考点→字幕文件）

```
知识地图一条考点（如"耦合7级"）
  → 看它所属小节（1.3 系统设计）
  → 归到知识点群（内聚耦合）
  → 在字幕目录筛  软件工程-内聚耦合_*.md  → 该群全部文件
  → 按素材"素材：834次/47篇"判断充足度（见4.3）
  → 挑播放量最高的1-2篇读
```

### 4.3 素材充足度判定（用"N次/M篇"的M值）

| M篇值 | 充足度 | 动作 |
|---|---|---|
| ≥20篇 | 充足 | 只读素材库索引/视频样本清单里播放量最高的1-2篇，其余不看 |
| 5-19篇 | 一般 | 该群文件全读也无妨，但优先精品短视频（如圆酱PV秒杀12min） |
| 3-4篇 | 偏少 | 全读 + 知识地图"要背的话"背死 |
| 0-2篇 | **缺口** | 不依赖字幕；改用 zst上午题#X-模块.md 长字幕，或直接背"要背的话" |

## 八、六环循环 × 单模块SOP 映射

> 用户学习循环：知识引入 → 知识学习 → 自我纠正 → 反复调试 → 继续下一个 →（到达状态即中断休息）
> 本章把§二的7步流程重挂到六环上，并重点设计「中断休息」环。

### 8.1 六环总图

```
   ┌──────────────────────────────────────────────────┐
   │                                                    │
   ▼                                                    │
①知识引入 → ②知识学习 → ③自我纠正 → ④反复调试 → ⑤继续下一个
   │                                            │
   └──── ⑥中断休息（触发信号出现即插入，不硬撑）◄┘
```

- 主循环：①→②→③→④→⑤ 走通一个考点/一个模块；
- ⑥休息环是**插入式**的，不在主线上排队——任何一环出现触发信号就跳出去休息，回来从**刚才卡住的那环**重新进，不往前赶进度。

### 8.2 六环 × 7步流程映射表

| 用户六环 | 对应SOP步骤（§二） | 用什么现有资产 | 该环退出标准 |
|---|---|---|---|
| **①知识引入** | 第1步 盘点考点 | 知识地图按「考频A在前→难度★★★在前→素材≥20篇在前」排序；素材库总索引定位考点群 | 圈出今天3-6条目标考点 |
| **②知识学习** | 第2步 首轮输入 | 字幕目录按「知识点群_BV号.md」筛文件；精品字幕优先（肥猫6min/圆酱12min等已下载） | 每条考点 ⚪→◐ |
| **③自我纠正** | 第3步 主动回忆自测 | 知识地图「要背的话」+「典型考法」字段；zst上午题#X字幕里的真题片段 | 复述≥80%要点 且 例题≥70%正确 |
| **④反复调试** | 第4步 弱点回补 ＋ 第6步 48h间隔回访 | 按§四素材映射定位具体字幕文件名→具体BV号；错题立即回退状态 | 复测通过；连续2次回访通过→✅ |
| **⑤继续下一个** | 第7步 转下一模块 | 知识地图该模块A类✅率统计 | A类✅率≥80% 且回访槽无新回退→开下一模块 |
| **⑥中断休息** | 触发信号清单（见§8.4） | §五时间盒的晚间硬截止时间；当日回访槽轻量收尾 | 回来先回访卡住的点，过了再继续 |

### 8.3 状态 × 动作判定表（⚪/◐/✅ 在自我纠正与反复调试环里怎么动）

| 考点当前状态 | 自测/回访/模拟结果 | 下一步动作 |
|---|---|---|
| ⚪未掌握 | 尚未开始 | 进今日首攻清单；按§四素材映射读1-2篇指定字幕 → 改◐ |
| ◐学习中 | 首轮学习后复述≥80% 且 例题≥70% | → **✅**，在知识地图该行登记「回访日期=今天+2」 |
| ◐学习中 | 复述<80% 或 例题<70% | 保持◐；按「知识点群_BV号」定位字幕**只读对应段落**；当日复测1次 |
| ◐学习中 | 当日复测仍不过 | **降级处理**：只背知识地图「要背的话」那一句话，不再深挖；进次日回访槽 |
| ✅已掌握 | 48h回访通过（脱稿复述≥80%） | 保持✅，回访计数+1；连续2次通过→**降频**（考前2天再滚） |
| ✅已掌握 | 48h回访失败 | **回退◐**；重读弱点对应字幕片段；次日回访槽再访 |
| ✅已掌握 | 整套模拟/真题该考点题目做错 | **强制回退◐**，不论之前连续回访通过过几次 |

### 8.4 中断休息环（重点设计）

#### 8.4.1 休息触发信号清单（出现任意一条，立即停手）

| # | 触发信号 | 判定方法 | 动作 |
|---|---|---|---|
| 1 | 同一考点连续2次回忆失败 | 合上知识地图复述，连续2遍要点缺失≥30% | 停手，短休15-20分钟 |
| 2 | 自测正确率连续3题下降/连错3题 | 做例题时连续3道越做越错 | 停止做新题，短休 |
| 3 | 连续40分钟以上注意力涣散 | 同一段字幕反复读3遍没进脑子 / 频繁抬手看手机 | 离开书桌15分钟 |
| 4 | 某考点看第2遍仍卡壳 | 同一字幕文件读了2遍，合上书仍说不出「要背的话」 | **换考点**，不硬磕；该考点进次日回访槽 |
| 5 | 到达晚间固定截止时间 | 写死一个时间（如23:30，按本人作息定） | 立即合上电脑，不刷新内容 |
| 6 | 身体信号（头痛/眼累/其他不适） | 主观出现即判 | 强制休息，学习让位于恢复（硬规则，不许扛） |

#### 8.4.2 休息动作（短休与日休分别怎么做）

- **短休（15-20分钟）**：离开屏幕、起身走动、喝水、拉伸；**不刷短视频**（会把残留注意力吃掉）；不聊考试相关话题。
- **日休（睡眠，服务记忆巩固）**：
  - 23:30前睡（按本人作息平移，但写死）；
  - **睡前30分钟不铺新内容**——只过当天最薄弱的1-2条考点（睡眠期间大脑自动巩固白天学的内容，睡前最后看的巩固效果最好）；
  - 48h间隔回访里的"48h"主要靠**隔夜睡眠**完成，不是靠挤时间多学。
- **一天节奏建议**：上午精力峰值攻难模块（①⑦③等★★★扎堆的）；下午动手做下午题模板（题1-题5）；晚间只做回访槽+状态更新（轻量认知负荷）；23:30硬截止。

#### 8.4.3 休息后回来做什么（固定三步）

1. **先回访刚才卡住的那一个考点**——不是继续往前赶进度；
2. 用知识地图「要背的话」重新脱稿复述：过了→回到原计划继续；还不过→按§8.3表降级处理（只背一句话），**不重复第3遍精读**；
3. 短休≤20分钟不算浪费：回来后该考点回忆通过率通常明显上升，直接接着走主循环。
